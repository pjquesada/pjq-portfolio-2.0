# pjq-portfolio-2.0

Personal portfolio for Pablo Quesada. The opening sequence is a pinned WebGL
domino composition choreographed with GSAP ScrollTrigger.

## Develop

```bash
npm install
npm run dev
```

## Art direction

Domino poses, model paths, and timeline windows live in `src/config/`. Point
`src/config/models.ts` at replacement GLB files without touching scene components.
